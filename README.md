# 📚 Notely — Your Collaborative Smart Notes Platform

**🌐 Live Website:** [https://parvanamohan.github.io/Notely/](https://parvanamohan.github.io/Notely/)

Notely is an educational web application designed to make note-taking, collaborative learning, study material preparation, and exam revision easier.

Users can create notes with a title, subject, and content, choose whether individual notes should be shared or private, upload PDF documents to generate study-friendly and exam-friendly notes, and take quizzes based on their learning materials. After submitting a quiz, users can view their results and review the correct answers to individual questions.

> **Educational Purpose Only:** Notely is a learning project developed for educational, experimentation, and demonstration purposes.

## 📌 About the Project

Notely brings note-taking, collaborative learning, study material generation, and quiz-based self-assessment together in one platform.

The website allows users to create their own notes, share selected notes with friends, keep other notes private, and prepare learning materials from uploaded PDF documents.

It also provides a quiz-based learning experience where users can practise with their notes, uploaded documents, and generated study-friendly or exam-friendly material. After completing a quiz, users can view their results and check the correct answer to each question.

The main aim of Notely is to explore how web technologies can support a more organized, interactive, and convenient learning experience.

## 🚀 How to Use Notely

### Creating a Note

1. Visit the [Notely website](https://parvanamohan.github.io/Notely/).
2. Navigate to the note creation section.
3. Enter the title of your note.
4. Specify the subject.
5. Add the content.
6. Create the note using the available controls.

### Sharing or Keeping a Note Private

1. Open the note you want to manage.
2. Choose the available visibility option.
3. Mark the note as shared if you want others to access it.
4. Keep it private if you prefer to use it personally.

### Uploading a PDF

1. Navigate to the PDF upload feature.
2. Select a supported PDF document.
3. Upload the document.
4. Choose the available study-friendly or exam-friendly notes option.
5. Review the generated learning material.

### Taking a Quiz

1. Open the quiz section.
2. Select the available notes or study material.
3. Open or generate a quiz.
4. Answer the questions.
5. Submit your answers.
6. View your results and review the correct answers.
